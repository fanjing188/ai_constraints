# 并行与子代理协作

> 只有真实并行、派发或复核子代理时读取。主代理始终负责最终整合、验证和交付。

## 分级交接

| 角色 | 必须提供的交接内容 |
|---|---|---|
| Explorer / Verifier | 问题、允许读取范围、预期输出；写入 Scope 为无 |
| Worker / DocSync | 目标与完成标准、精确写入 Scope、禁止事项、验证要求、返回格式 |
| R3 Worker | Worker 全部内容，另加核心不变量、直接消费者、迁移、发布顺序与回滚边界 |

## 并发边界

- 写入 Scope 不得重叠；有实际冲突风险时由主代理先登记 `ai_constraints/codex/任务池.md`，冲突 Scope 不并行。
- 只读任务和完全不重叠写入无需登记；子代理不得修改锁、扩大权限或自行添加兜底。
- Explorer 返回前不重复排查同一区域；多个独立任务先连续派发，再统一等待。
- 发现未提交冲突、越权需求或前置证据不足时停止对应写入并返回原始事实。

## 主代理复核

- 检查实际 diff、写入边界与未提交改动，不只接受代理摘要。
- 复核运行过的命令是否覆盖档案中的不变量、消费者与本次风险。
- 由主代理整合产物、执行最终闭包并交付实际证据。
