# 项目模块地图

<!-- ai-constraints:generated:start -->
## 项目快照

- **目标**：为嵌入式项目提供分级开发规则、确定性清单、一次初始化和任务收尾增量同步。
- **技术栈**：Markdown、Python 3 标准库、POSIX shell 与 Git。
- **真实入口**：`ai_constraints/AGENTS.md`、`ai_constraints/scripts/verify.sh`、`ai_constraints/scripts/project_inventory.py`。

## 模块索引

| 模块 | 根目录 | 职责 | 权威档案 |
|---|---|---|---|
| 日常规则 | `ai_constraints/codex/` | R0–R3 路径、风险与收尾同步边界 | `ai_constraints/codex/入口.md` |
| 项目清单 | `ai_constraints/scripts/project_inventory.py` | 文件枚举、指纹、变化与托管区机械操作 | `ai_constraints/scripts/project_inventory.py` |
| 工作包验证 | `ai_constraints/scripts/verify.py` | 规则、Skill、状态与仓库卫生门禁 | `ai_constraints/scripts/verify.py` |
| 项目建档 | `ai_constraints/.agents/skills/` | 一次初始化、任务收尾增量同步与必要全量重扫 | `ai_constraints/.agents/skills/project-initialize/SKILL.md` |

## 跨模块依赖

- 两个 Skill 依赖 `ai_constraints/scripts/project_inventory.py` 提供机械事实，再由 Codex 按代码、引用和测试证据判断语义影响。
- `ai_constraints/scripts/verify.py` 同时验证规则、Skill、托管标记和初始化状态；不替代目标项目业务测试。

## 全局契约与风险

- 项目事实保持“核心不变量 → 实现入口 → 直接消费者 → 可执行验证命令”闭环；证据不足保留 `UNKNOWN`。
- 机械分类是保守信号；未映射、`UNKNOWN` 或文件名提示先局部核对，只有真实结构变化或影响半径仍未知才全量重扫。
- 目标项目路径始终相对 Git 根；秘密内容、业务源码和 manual 区块不得被工作包读取后写回或覆盖。
