# AI Constraints

将整个目录放到目标 Git 项目根的 `ai_constraints/`，从该目录启动 Codex，并显式调用一次 `$project-initialize`。初始化会扫描第一方文本、生成项目档案，并在项目根接入规则与两个 Skill。

初始化后直接从目标项目根进行日常开发。修改任务完成代码与验证后，Codex 按 `ai_constraints/codex/入口.md` 将 `$project-update` 作为默认收尾步骤；也可随时手动调用。稳定事实未变化时保持零 diff，变化时只同步受影响档案。

增量分析优先局部读取和引用检索。只有状态损坏、历史改写、真实模块拓扑或主要构建入口变化，或局部核对后仍无法确定影响半径时才全量重扫。工作包不读取秘密内容，不修改业务代码、测试、依赖、CI 或生产配置，也不会提交、推送或部署。
